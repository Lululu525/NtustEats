## 變更內容
1. **全 App 化介面**：移除網頁上方列與手機外框；學生、店家、管理者都是全螢幕 App 版面，底部分頁列（學生：餐廳／購物車／我的訂單／我；店家：訂單／菜單／設定；管理者：店家／菜單／報表）。
2. **店家訂單**：手機上以分段切換（新訂單／製作中／可取餐）；平板（寬度 ≥ 760px）自動並排三欄。
3. **可安裝（PWA）**：`prototype/manifest.webmanifest`（名稱「台科學餐」、主色、圖示）、`prototype/sw.js`（快取 App 外殼，可離線開啟）、`prototype/icons/`（192、512、180、maskable 512）。
4. Demo 時鐘移到「我」／「設定」／「報表」頁與封面的「Demo 時鐘（測試用）」。

## 安裝方式（需 HTTPS，例如 GitHub Pages）
- Android Chrome：開啟網址 → 選單「安裝應用程式」。
- iPhone Safari：開啟網址 → 分享 →「加入主畫面」。
