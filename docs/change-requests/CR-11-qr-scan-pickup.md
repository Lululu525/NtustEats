# CR-11 取消「學生自行按完成訂單」，改由店家核對後完成取餐

| 項目 | 內容 |
|---|---|
| 提出者 | 陳庭瑜（PO，2026-11-20 提出） |
| 狀態 | 原型已實作，待審查 |
| 取代 | CR-07 第 1、2 點（學生按「完成訂單」、店家「交付餐點」） |

## 變更內容
1. **取消學生自行按「我已取餐，完成訂單」**。學生取餐時出示「我的訂單」裡的 QR Code（或報 4 碼訂單號碼），由店家核對，**核對成功訂單即變成「已完成」**。
2. 店家核對方式維持兩種（FR-18 原有內容，不變）：
   - **📷 掃描 QR Code**：用平板／手機相機掃描學生的訂單 QR Code。
   - **🔍 輸入訂單號碼**：在訂單頁最上方輸入號碼（如 T101）後按「核對取餐」。
3. 核對結果：
   - 本店、狀態為「可取餐」→ 取餐完成，記錄核對時間（`scannedAt`）與方式（`pickupMethod`：QR／NO）。
   - 不是本店訂單、已取過餐、尚未可取餐、不是台科學餐的 QR Code → 顯示原因，不改變訂單。
4. CR-08 放鳥更正：店家按「更正放鳥，改回可取餐」後，訂單回到「可取餐」，仍需店家核對才算完成。
5. CR-07 第 3 點不變：有未完成訂單時不能點下一餐；店家核對完成後即可再點。
6. 撥款：店家核對完成或標記未取餐的訂單才轉為待撥款（原為學生按完成）。

## 實作說明
- QR Code 內容沿用原本的 `NTUSTEATS:<訂單 token>`（隨機值，NFR-06）。
- 相機掃描使用 `getUserMedia` + jsQR 1.4.0（Apache-2.0，嵌入於 `prototype/src/jsqr.min.js`）；需 HTTPS（GitHub Pages）並允許相機權限。沒有相機時可用輸入號碼。
- PWA 快取版本 v10 → v11；原型版本 0.5.0 → 0.6.0。

## 對需求的影響
- **FR-18**：不需修改（原本即為「店家掃描 QR Code 或輸入 4 碼訂單號碼核對取餐」）。
- **FR-15 / State Machine**：READY → PICKED_UP 的觸發者由「學生按完成」改為「店家核對成功」；移除 HANDED_OVER 中間狀態。（待審查）
