## 變更內容
1. 訂單最後一步「已取餐」改為「已完成」，由**學生自己在 App 按「我已取餐，完成訂單」**。
2. 店家端「已取餐」改為「交付餐點」（或用號碼／QR 核對）→ 訂單標記「已交付，等學生按完成」；店家不再直接結束訂單。
3. 學生只要有**未完成的訂單**（已送出／製作中／可取餐），就**不能結帳下一筆**：首頁、購物車、結帳頁顯示提示並停用按鈕，引導到「我的訂單」。可以先瀏覽、加入購物車。
4. 放鳥判定：店家已交付的訂單不算放鳥（學生拿了但忘記按完成）。

## 建議修改的需求（待審查）
- **FR-15（改）**：店家狀態更新為 已接單 → 可取餐 → 已交付；「已完成」由學生確認。
- **FR-29（新）**：學生有未完成訂單時，系統不得允許送出新訂單，並提示需先完成。
- **FR-20（改）**：放鳥判定排除「店家已交付」的訂單。
- State Machine：READY 新增子狀態 HANDED_OVER；PICKED_UP 改名 COMPLETED，觸發者為學生。
