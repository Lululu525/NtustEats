# CR-10 校內儲值機儲值 → 學校代收 → 撥款給店家

| 項目 | 內容 |

## 背景
CR-06 讓學生可以用「校園帳戶」付款，也可以到校內儲值機儲值。但原本只有學生端的餘額，
**沒有說明儲值機的錢怎麼跟系統連起來，也沒有說明錢最後怎麼進到店家**。

## 金流設計

```
學生投現金 ──▶ 校內儲值機 ──▶ 學校代收帳戶（校園帳戶餘額 +）
                                     │
學生點餐付款（校園帳戶／LINE Pay）──▶ 學校代收中（標記是哪家店、哪張訂單）
                                     │
            ┌────────────────────────┼─────────────────────────┐
     取消／店家拒絕               學生按「完成訂單」            店家標記「未取餐」
     ▼                            ▼                              ▼
  自動退回校園帳戶／LINE Pay     待撥款                         待撥款（已付不退）
                                     │
                     總務處定期結算（例：每週一次）
                                     ▼
                  匯入店家登記的銀行帳戶，產生撥款單（P＋日期＋序號）
```

1. **儲值機怎麼連到系統**：儲值機刷學生證讀到學號，投入現金後，儲值機呼叫學校帳務系統（本系統的「儲值 API」）寫入一筆儲值紀錄：學號、金額、機台編號、儲值單號、時間。學生的校園帳戶餘額立刻增加。現金每天由出納從機台收回，存入學校代收帳戶。
2. **錢不直接給店家**：學生付款時，錢先由學校（總務處）代收保管，訂單上記錄是哪家店。這樣取消或店家拒絕時可以直接退款，不用找店家要錢。
3. **什麼時候算店家的錢**：學生按「完成訂單」（CR-07），或店家標記「未取餐」（已付款不退），訂單轉為「待撥款」。
4. **怎麼進到店家那邊**：總務處在「帳務」頁按「執行撥款」，系統把每家店的待撥款加總，扣手續費後匯入店家登記的銀行帳戶，並產生撥款單；店家在「帳務」頁看得到撥款紀錄和每一筆訂單的狀態。
5. **對帳**：儲值總額 − 校園帳戶付款 ＋ 退款 ＝ 學生餘額合計。總務處帳務頁會自動檢查。

## 原型實作
- **學生**（我 → 校園帳戶）：可選儲值機 K01 第一餐廳、K02 第二教學大樓餐廳、K03 圖書館，投 $100／$500／$1000，產生儲值單號。
- **店家**（新分頁「💰 帳務」）：今日線上收款、學校代收中、待撥款、已撥款；收款明細（每筆訂單是代收中／待撥款／已撥款）；撥款紀錄；錢怎麼進到店家的流程說明。
- **總務處**（編輯模式 → 新分頁「💰 帳務」）：各儲值機今日收現、學生餘額合計、各店代收中／待撥款／已撥款、「執行撥款」按鈕、對帳檢查、最近帳務紀錄。
