## 變更內容
1. **封面分流**：校內學生／教職員、其他校外人士、**店家** 三個入口；登入後依身分進入對應畫面，**移除上方「學生端／店家端／總務處」切換**（原型展示用，正式系統不應讓使用者自行切換角色）。
2. **店家登入**：下拉選單選店家＋輸入密碼（預設 `0000`）；店家只能看到自己的訂單與菜單；可在「時段與密碼」變更密碼。
3. **管理者編輯模式**（類似 Moodle 的「編輯模式」開關）：總務處管理人員以校內身分登入後，右上角出現「編輯模式」開關。
   - 開啟：進入管理畫面 —「店家管理」（新增店家、修改店名／營業時間／備餐時間／時段上限、重設店家密碼）、「菜單設定」（新增／修改／刪除分類與品項、價格、標籤）、「訂單報表」。
   - 關閉：回到一般點餐畫面，管理者也能以校內價點餐。

## 建議新增／修改的需求（待審查）
- **FR-03（修改）**：管理者應能新增店家並設定店名、營業時間、價格模式（分校內外價／單一價格）、備餐時間、時段上限與初始密碼。
- **FR-24（新增）**：店家以「店家名稱＋密碼」登入，預設密碼 0000，首次登入後應變更。
- **FR-25（新增）**：管理者帳號可切換「編輯模式」；開啟時才可修改店家與菜單，關閉時為一般使用者畫面。
- **FR-26（新增）**：管理者可新增、修改、刪除菜單分類與品項；刪除前需二次確認。
- **NFR-09（新增）**：角色權限 — 學生／訪客不得看到店家與管理功能；店家只能存取自己的店。
