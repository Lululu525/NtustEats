## 與既有需求的差異（需要審查決定）
1. **只有一種價格**：線上菜單沒有「校內優惠價／校外販售價」之分 → BR-01 需補充「單一價格店家校內外同價」。
2. **營業時間不完整**：只寫「10:30 開始供應、休息時間 14:30–16:30」，晚餐結束時間不明 → 原型暫設 19:30，**待向店家確認**。
3. **熱量標示**：餐盒附熱量（約 453～792 大卡）→ 可能成為新的顯示需求（FR-04 標籤），需先確認學生是否需要。
4. **英文名稱與中文不符**：iCHEF 上「高鈣吻仔魚餐盒」的英文寫成 Provence-Style Sea Bass Bento、「蔥薑佐白旗片」寫成 Lemon Pepper Salt White Fish Fillet → 原型依中文改寫英文，**需請店家確認**。
