# CR-08 店家可更正「未取餐」

## 背景
店家把訂單標成「未取餐」後，學生其實只是晚到，最後還是有來拿。原本「未取餐」是終點狀態，無法改回，學生會被錯記一次放鳥（30 天內 2 次會停權 14 天），而且訂單卡住、無法點下一餐。

## 變更內容
1. 店家端「今日已結束」列表中，狀態為「未取餐」的訂單出現按鈕 **「更正為已交付」**；需再按一次「確定更正（取消放鳥紀錄）」才生效（兩段確認，避免誤按）。
2. 更正後訂單回到「可取餐＋已交付」，標記「已更正」，並寫入歷程 `NO_SHOW_CORRECTED`。
3. 撤銷這筆放鳥：重新計算該學生的放鳥次數，若不足 2 次則解除停權。
4. 學生端收到通知「店家已更正訂單為已交付，請按完成訂單」，訂單卡顯示「店家已更正：你有來取餐」，學生按完成後結束（沿用 CR-07）。

## 建議修改的需求（待審查）
- **FR-20（改）**：店家可在當日將「未取餐」更正為「已交付」，系統須撤銷該次放鳥紀錄並重新計算停權。
- **FR-30（新）**：所有狀態更正須留下歷程（誰、何時、從何狀態改成何狀態），供總務處稽核。
- State Machine：新增轉換 `NO_SHOW → READY [店家更正] / 撤銷放鳥、重算停權、通知學生`。
